# PiContextLab 框架验收

主线是 core 层的可选上下文/工具策略，PiMetricLab 是验证客户端。

- 模型声明与本轮执行集合一致，未被选择的工具不能执行。
- 工具数量与 schema 字节预算、完整依赖闭包和必选组拒绝行为可核查。
- 目录缓存有界、就地元数据修改可失效；只复用统计，工具选择和执行对象始终来自当前注册表。
- system 与当前用户轮不被静默裁剪，工具事务完整，原文按身份可回读。
- batch recall 完整性检查、会话隔离、共享 Unicode 限额、逐路径错误处理与按实际返回长度续读。
- 路由后实际超预算才外置；多个低于单条阈值的结果累积超限时仍可按净节省外置；满足预算即停止，最近并行回读整批保护，不改权威历史。
- 可选字段定位遵守扫描/响应预算；数字回查保留大整数、小数、指数及负零原始字面。
- 可选schema拒绝反馈保留诊断与字段形状，序列化content不超2KiB，完整参数不改、验证与执行边界不放宽，正常与恢复路径一致。
- 可选同一assistant批次的共享回读字节预算；执行前确定分配，最终content再次检查，精确游标按实际返回量推进，元数据放不下明确延后；恢复按原整批分配，预算不可行时执行前失败并结束事件流。
- 可选响应后的纯回读空间规划，计入实际assistant参数、完整空结果事务及通常包装余量；策略只能收紧宿主预算。方案先与已保存响应绑定、再开始工具，恢复不按剩余调用或改变后的上下文重分配；混合批次保留静态预算与发送前硬上限。
- 原始 npm 1.6.0 独立基线、公开目录评测、真实 DeepSeek 研究及失败分别留存。
- 工程通过不等于效果提升；当前负结果属于验收材料，不能删除或重试挑分。

## PiMetricLab 客户端验收

PiMetricLab 面向电商分析人员调查经营指标变化：接入订单明细，明确指标与时间口径，比较可比区间，拆解国家或商品的变化贡献，导出能够回到查询证据的复盘报告。使用 Pi 的 agent core 与模型接口构建业务应用。

## 功能流程

1. 从显式 CSV 清单导入数据，保存原文件哈希、字段映射、行数、质量统计及不可变数据集版本。UCI Online Retail 完整真实数据作为一个验收输入；合成夹具单独标记。
2. 指标目录说明币种、粒度、退货、零价/负价及缺失客户标识处理。金额使用定点十进制，订单数按订单而非明细行计算；不把净销售额命名为已收款。
3. 使用真实 Pi Agent 和严格工具 schema 组织数据概况、期间比较、维度贡献及报告提交。模型选择步骤，确定性引擎负责计算与校验。
4. 检查数据覆盖与期间可比性。数据只到月中时，不能把完整上月与未完整本月的差异直接作为经营异常；需要明确选择时间范围。
5. 为每条查询保存 SQL、绑定参数、口径版本、数据版本、结果哈希与引用 ID。维度变化贡献含剩余分组，并与总变化核对。
6. 报告数字由已保存证据生成。模型解释与待验证假设单列；审核记录绑定报告版本。Agent 工具不能替人完成审核。
7. 持久任务、模型调用与工具结果支持取消、重启恢复、固定额度、重复请求复用以及单任务写入归属检查。未知尝试计入原额度。明确声明中断点的实际验证范围。
8. 提供本地 Web 工作台，展示数据集、提问、任务进度、工具证据、复盘报告、澄清和审核；刷新后能重新读取任务，支持离线报告导出。

## 工程与效果验证

- 严格类型检查、构建及有意义的业务/持久化/API 集成测试。
- 精确算术、订单粒度、退货、空组、非法输入、不可比区间、证据错版本、重复提交、未知额度、取消及跨进程恢复等实际边界。
- 完整真实数据导入与查询，同独立计算程序核对一组事先确定的指标和贡献结果。数据质量以实际检查为准，不照抄数据卡的缺失值声明。
- 实际 Pi 运行时配合脚本化 provider 验证工具循环；真实模型调用另设小额度、独立报告，不将脚本用例当作模型准确率。
- 浏览器实际操作、桌面/窄屏布局及导出检查，保留可运行演示。
- 交付源代码、冻结依赖、启动说明、原始结果索引、完整中文讲解和能按事实使用的简历条目。

## 本版范围

单租户、可信本机或内网分析工作台；订单事实通过明确导入进入只读分析库。贡献拆解描述统计变化，不自动证明因果。商业部署、多租户权限、在线支付、任意数据库写入和大模型训练不属于本版。
