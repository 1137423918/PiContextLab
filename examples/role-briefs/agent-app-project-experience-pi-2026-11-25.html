PiContextLab - Agent上下文预算与工具选择改造

TypeScript / Pi Agent Core / DeepSeek API / BM25 / SQLite / DuckDB

  • 基于Pi/DeepSeek实现经营指标调查：先澄清口径与期间，再比较六类指标、拆解国家/商品贡献，绑定SQL证据并导出报告；工具不接受任意SQL或shell。
  • 用SQLite维护owner/epoch写入归属、固定请求额度、完整回复和工具缓存；将执行集合、响应与回读方案绑定，恢复复用原批次，未知尝试仍扣额。
  • 在同一封存事务中核对结构化声明的数值、方向、贡献组及来源；独立程序核对541,909行数据上的12个指标值和29个国家分组。

101项工程测试、14项浏览器检查通过；来源一致不等于因果或人工审核，报告复核单列。
